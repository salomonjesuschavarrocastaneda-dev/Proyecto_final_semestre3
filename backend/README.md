# 🟩 Grupo 2 — Backend

El backend será desarrollado con **Django**.

## Tecnologías

- Python
- Django
- MySQL

## Instalación inicial

Desde esta carpeta:

```bash
python -m venv venv
```

Activar el entorno virtual y después:

```bash
pip install django mysqlclient python-dotenv
```

Crear el proyecto:

```bash
django-admin startproject config .
```

Crear la aplicación:

```bash
python manage.py startapp inventario
```

> El Grupo 2 debe coordinar con el Grupo 3 la estructura definitiva de la base de datos.
